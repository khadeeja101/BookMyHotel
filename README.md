# BookMyHotel - Online Hotel Booking Application

BookMyHotel is an online hotel booking platform built with Python Flask. The system connects four major hotel chains (**The Marriott**, **The Hilton**, **The Hyatt**, and **The Four Seasons**) across Europe and Asia.

It supports dynamic rates, promotions, guest reviews, user registration with email verification, secure payments, and an admin analytics dashboard.

---

## Quick Start (Running with MySQL)

This application is pre-configured to use **MySQL** as its database system.

### Step 1: Install Dependencies
Install the required packages from `requirements.txt`:
```
pip install -r requirements.txt
```

### Step 2: Setup Database Connection (.env)
Create `.env` file in the project root from `.env.example` file

### Step 3: Run the Application
Start the Flask development server:
```
python app.py
```
Open your browser and navigate to: **`http://localhost:5000`**
